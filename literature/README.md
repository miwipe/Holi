# Literature analysis

`R/` holds the existing plotting project. Run `Rscript literature/R/generate_figures.R` from the repository root, or open `R/sedaDNA_litterature.Rproj` in RStudio. The plotting definitions and output names are unchanged; outputs resolve to the repository's `figures/` directory.

`R/sandbox.R` is exploratory code, not the production figure generator. The Google Drive `.gsheet` shortcut is retained; the source URL and dataset semantics are documented in [Literature and figures](../docs/wiki/Literature-and-figures.md).

The former long literature folder name and its `sedaDNA_lit_map/` subdirectory remain compatibility links. PDFs stay in the separate curated literature folder outside the repository.
