# Holi documentation

Holi combines preprocessing, competitive mapping, taxonomic assignment, and authenticity assessment for ancient metagenomic data, with a focus on eukaryotic ancient environmental DNA.

## Run an analysis

1. [Install the environment and required tools](Getting-started.md).
2. [Prepare reference catalogues](Reference-catalogue.md), input names, and configuration.
3. [Run Holi](Running-Holi.md) through the [eight analysis stages](Pipeline-workflow.md).
4. Inspect [authentication evidence](Authentication.md) and [postprocessing outputs](Postprocessing.md).

## Explore the literature

Use the [literature explorer](https://miwipe.github.io/Holi/) and [source spreadsheet](https://docs.google.com/spreadsheets/d/13cmBUi4cigUaTKtQeFLFvS0gXT8AeWxWKzHv2UcOBCI/edit#gid=0), or [regenerate the original figures](Literature-and-figures.md).

The `holi_dev` documentation describes the current checked-in scripts. Butteracid and some optional visualisation workflows remain under development. Original wiki material is retained in the main repository under `docs/wiki-archive/` for comparison and provenance.
