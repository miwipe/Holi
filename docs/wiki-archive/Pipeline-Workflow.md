## Holi: A Command-Line Workflow for Ancient DNA Analysis

Holi is a command-line workflow designed for the analysis of ancient metagenomic data using a competitive mapping approach. In this method, all trimmed and quality-controlled reads are given an equal opportunity to align against all references in a database or set of databases. The database setup is structured to include a representative reference genome from each organism, ensuring accurate taxonomic classification of each read.

To authenticate and validate that the DNA originates from ancient (dead) organisms, Holi employs a suite of tools to analyze key criteria such as:

Read length distributions
DNA damage patterns (e.g., cytosine deamination)
Genome coverage and coverage evenness
This comprehensive approach makes Holi a powerful tool for ancient DNA researchers, enabling robust taxonomic classification and authenticity assessment.
