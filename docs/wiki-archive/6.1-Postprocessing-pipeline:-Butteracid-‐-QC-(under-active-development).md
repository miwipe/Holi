Documentation for the butteracid workflow for postprocessing analysis after the Holi pipeline:

* `butteracid.sh` (Bash wrapper)
* `butteracid_unicorn.R` (R post-processing for `MODE="unicorn"`) - find the complete description in part 2
* `butteracid_bamfilter.R` (R post-processing for `MODE="bamfilter"`) - find the complete description in part 2

The pipeline is structured in **two major phases**:

1. **QC generation** (Bash: mapped read counts + seqkit stats for FASTQs)
* **NOTE:** The QC generation script is adapted from https://github.com/GeoGenetics/dreamcatcher QC script.
2. **Downstream post-processing** (R: collect unicorn/bamfilter output files, attach taxonomy, run metaDMG filtering, produce merged tables ready for plotting results)

---

# Part 1 — Bash Wrapper (`butteracid.sh`)

## 1) Strict Bash mode: fail early and safely

At the top, the script uses:

```bash
set -euo pipefail
```

This means:

* `-e` → stop if any command fails
* `-u` → error on undefined variables
* `-o pipefail` → pipeline fails if any command fails

This prevents silent failures and incomplete outputs.

---

## 2) Optional flag: `--force-qc`

The script allows optional QC regeneration:

```bash
./butteracid.sh --force-qc config.sh
```

Code:

```bash
FORCE_QC=false
if [[ "${1:-}" == "--force-qc" || "${1:-}" == "--force-QC" ]]; then
    FORCE_QC=true
    shift
fi
```

If enabled, QC generation will run even if the QC output already exists.

---

## 3) Load configuration

The script expects a config file path:

```bash
CONFIG_FILE="$1"
source "$CONFIG_FILE"
```

It then validates key variables:

```bash
: "${MODE:?MODE not set in config file}"
: "${LIBRARY_LIST:?LIBRARY_LIST not set in config file}"
...
```

If any required variable is missing, the script exits immediately.

## 4) Load required modules

The script loads samtools; this needs to be adjusted to the HPC environment that is used. ```samtools``` is *not* provided in the conda environment.

```bash
module load samtools
```

## 5) Helper function: `get_seqkit_stats_16()`

This function extracts **16 statistics** from a FASTQ using SeqKit.

### What it does

* runs:

```bash
seqkit stats -a -T file.fastq.gz
```

* extracts the relevant columns (4..NF)
* ensures exactly 16 values
* if the FASTQ is missing → returns 16 `"NA"`

Code excerpt:

```bash
line=$(seqkit stats -a -T "$fq" \
       | awk 'NR==2 {for(i=4;i<=NF;i++) printf "%s%s", $i,(i==NF?ORS:OFS)}')
```

### Why it matters

The QC table must have a fixed number of columns. This function guarantees the output stays consistent even if files are missing or SeqKit returns fewer fields.

## 6) Per-library processing: `process_library()`

This function does the QC work for **one library ID**.

### 6.1) Compute mapped reads from microbial BAM

Input:

```bash
$BAM_BASE/${LIB_ID}.gtdb.merged.bam
```

Output field:

* `total_no_reads_mapped_uniq`

Method:

```bash
samtools view "$bam" \
  | cut -f1 \
  | sort -u --temporary-directory="$SCRATCH_DIR" \
  | wc -l
```

This counts the number of **unique read IDs** in the BAM.

---

### 6.2) Compute mapped reads from prefilter BAM

Input:

```bash
$PREFILTER_BAM_BASE/${LIB_ID}.comp.bam
```

Output field:

* `total_no_reads_mapped_uniq_prefilter`

Same method as above.

---

### 6.3) Define the FASTQ files to summarise

For each library, it expects 6 FASTQ files:

```bash
local FASTQS=(
  $FASTQ_LANE_BASE/${LIB_ID}_L001_R1_001.fastq.gz
  $FASTQ_LANE_BASE/${LIB_ID}_L002_R1_001.fastq.gz
  $FASTQ_LANE_BASE/${LIB_ID}_L003_R1_001.fastq.gz
  $FASTQ_LANE_BASE/${LIB_ID}_L004_R1_001.fastq.gz
  "$FASTQ_LOW_COMPLEXITY_BASE/${LIB_ID}.ppm.vs.d4.fq.gz"
  "$FASTQ_PREFILTER_BASE/${LIB_ID}.euk.fastq.gz"
)
```
**NOTE**: The ending of the fastq files can differ to the ones used here. Please correct and adjust any FastQ file endings as necessary.
---

### 6.4) Collect SeqKit stats for all FASTQs

Each FASTQ produces 16 metrics:

* 6 FASTQs × 16 metrics = **96 columns**

The script collects them into an array:

```bash
for fq in "${FASTQS[@]}"; do
  read -r -a stats <<< "$(get_seqkit_stats_16 "$fq" "$LIB_ID")"
  SEQKIT_LINE+=("${stats[@]}")
done
```

---

### 6.5) Emit a QC output row

Final output row =:

```
LIB_ID mapped_reads_uniq mapped_reads_uniq_prefilter 96_seqkit_fields
```

Code:

```bash
echo "${LIB_ID} ${STAT_G} ${STAT_H} ${SEQKIT_LINE[*]}"
```

---

## 7) QC table generation logic

If QC output exists and is non-empty **and** `--force-qc` is not used → it skips QC.

```bash
if [[ -s "$QC_OUTPUT" && "${FORCE_QC:-false}" == false ]]; then
    echo "[INFO] Found existing non-empty QC table..."
else
    echo "[INFO] Generating QC table..."
```

---

## 8) QC header creation

The script writes a long header listing all columns:

```bash
echo "library_id total_no_reads_mapped_uniq total_no_reads_mapped_uniq_prefilter ..." > "$QC_OUTPUT"
```

---

## 9) Process all libraries in parallel

The library IDs are read from `LIBRARY_LIST`.

```bash
parallel -j 10 process_library :::: "$LIBRARY_LIST" >> "$QC_OUTPUT"
```

This runs **10 libraries at once**, appending each row to the QC table.

---

## 10) Run downstream mode (`bamfilter` vs `unicorn`)

Based on `MODE`, the script runs a different R pipeline:

```bash
case "$MODE" in
    bamfilter)
        Rscript butteracid_bamfilter.R "$CONFIG_FILE"
        ;;
    unicorn)
        Rscript butteracid_unicorn.R "$CONFIG_FILE"
        ;;
esac
```
