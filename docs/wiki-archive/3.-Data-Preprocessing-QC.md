## Trimming and QC of raw demultiplexed reads

### 1. Sample list
The input data are raw demultiplexed reads as FASTQ files. In the folder your data is saved, generate a sample list to simplify all future commands.
```
ll *R1_001.fastq.gz | awk '{print $9}' | cut -f1 -d_ | uniq > sample.list
```
Function:
The command lists all files matching the suffix ```R1_001.fastq.gz```. The listing has 9 different columns of file information. The 9th column lists the file name, which we extract using ```awk '{print $9}' ```. The output is piped into a cut command, which extracts the string before the first ``` _ ```. We keep every unique prefix string for the sample list.
Every unique string in the sample list ``` sample.list ``` represents a unique sample ID and is used as separate input for each command. The longer the sample list, the more commands have to be run in parallel, and computational specs such as time and memory should be adjusted accordingly.

### 2. Trimming and merging
The first step is to trim the adapters for the raw input FASTQs and merge the forward (R1) and reverse (R2) reads:

```
cat sample.list | parallel -j 5  'fastp  -i {}*R1*.fastq.gz -I {}*R2*.fastq.gz -m --merged_out {}.ppm.fq -V --detect_adapter_for_pe -D --dup_calc_accuracy 5  -g -x -q 30 -e 25 -l 30 -y -c -p -h {}.fastp.report.html -w 1'
```
Function:
For every sample ID in the sample list, sequencing adapters are trimmed using the program ``` fastp ```.
  - ``` parallel -j 5 ``` allows the ``` fastp ``` command to run on 5 jobs simultaneously (that means it will run 5 sample IDs at a time; the number can be adjusted depending on the available resources) 
  - ``` -i ``` forwards FASTQ input: the command replaces {} with a sample ID from the sample.list; the same goes for ``` -I ``` for the reverse FASTQ input. 
  - ``` -m ``` enables merging of paired-end reads
  - ``` --merged_out ``` specifies the output suffix creating a new file name for the merged FASTQs consisting of the sample ID and the output suffix 
  - ``` -V ``` 
  - ``` --detect_adapter_for_pe ``` automatically detects adapters for paired-end data (can be customised for specific adapters; default adapters used: ```--adapter_sequence=AGATCGGAAGAGCACACGTCTGAACTCCAGTCA --adapter_sequence_r2=AGATCGGAAGAGCGTCGTGTAGGGAAAGAGTGT``` (see: https://github.com/OpenGene/fastp))
  - ``` -D ``` enable deduplication  
  - ``` --dup_calc_accuracy``` level of accuracy for the deduplication (int between 1 to 6) 
  - ``` -g ``` enables poly G detecting and trimming (default length is 10bp)
  - ``` -x ``` enables poly X detecting and trimming (default length is 10bp)           
  - ``` -q ``` minimum base quality (PHRED score based)
  - ``` -e ``` average quality score (PHRED score based)
  - ``` -l ``` minimum read length
  - ``` -y ``` enable low complexity filtering -> defined as a percentage of bases that differ from the following base (default value: 30; can be specified ```-Y [int 1-100]```)
  - ``` -c ``` enables base correction for paired-end data (the decision is based on the base quality of the overlapping bases. **Note**: requires a minimum overlap length of 30, a base difference limit for the overlap of 5 bases and 20% in total - parameters are adjustable (see https://github.com/OpenGene/fastp).  
  - ``` -p ``` enables overrepresentation analysis (default: counts sequences of length 10, 20, 40 and 100 bp). 
  - ``` -h ``` creates a QC report HTML
  - ``` -w ``` number of threads

### 3. Duplicate removal

We then remove duplicates using **vsearch**
```
cat sample.list | parallel -j 20 'vsearch --fastx_uniques {}.ppm.fq --fastqout {}.ppm.vs.fq --minseqlength 30 --strand both'
```
Function:
As before, we parallelise the command, allowing for 20 Samples to run simultaneously.
  - ``` --fastx_uniques ``` identifies duplicates in FASTQ/FASTA input 
  - ``` --fastqout ``` output of deduplicated FASTQ file of sample
  - ``` --minseqlength ``` minimum read length 
  - ``` --strand ``` duplicate check for plus or both strands

### 4. Low-complexity filtering

**SGA** is used to remove complex reads like:
***ATATATATATATATATATATATATATATATATATATATATATATAT***

```
cat sample.list | parallel -j 20 'sga --dust {}.ppm.vs.fq > {}.ppm.vs.d4.fq'
cat sample.list | parallel -j 20 'gzip {}.ppm.vs.d4.fq' 
```

Function:
  - ``` --dust ``` 

At the end we want to make sure that our files are gzipped and intermediate files are deleted:
```
rm *.ppm.fq *.ppm.vs.fq
```

At this point of the Holi pipeline, your output files end with the suffix ``` .ppm.vs.d4.fq.gz ```. 
These files are your input for the next steps in the pipeline.
