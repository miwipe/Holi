For nearly all steps, we will be working in a command line interface, all steps below have been tested on a Mac Book Pro and Linux server. Please bear in mind that some of the tools here can require a lot of memory depending on your data and the database you are using. It can also run for days and hence we recommend you node to have with +500 Gb and 24 cpus.

First, make sure you have git installed on your machine. Check if it is there by typing following command in your terminal

```
git --version
```
This should print the version, if not please go to https://git-scm.com/downloads and finish the installation before continuing. 

We will use [conda](https://docs.conda.io/projects/conda/en/latest/user-guide/getting-started.html) to install and manage our tools when possible.  

Conda is an open-source package and environment management system that simplifies software installation and dependency management, particularly for Python and data science applications. It allows users to install, update, and manage software packages while also enabling the creation of isolated environments to prevent conflicts between dependencies. Conda supports multiple programming languages, including Python and R, making it a versatile tool for scientific computing. Users can create a new environment with a specific Python version, activate it, and install necessary packages with simple commands. This approach ensures reproducibility and flexibility in managing different projects with varying requirements.

Let's create the conda environment using the holi.yml environment file from the bin folder. 


Lets create both environments (NOTE! that each will take a bit of time ~5 min)! 
```
conda env create -f holi.yml
```
and then activate the environment
```
conda activate holi.yml
```

We then install bam-filter in the holi using pip
```
pip install bam-filter
```

For your information we have also installed the following programmes that are not part of the conda packages and needs manual installation:
