# Postprocess unicorn + metaDMG

## Description of the Rscript pipeline of butteracid (continued from 6.1)

This pipeline postprocesses two analysis outputs per library/sample:

* **metaDMG** (LCA/stat tables; includes damage-fit related columns like `fwf*` and `fwdx*`)
* **unicorn** (reference statistics per accession, plus accession→taxid mapping)

It then:

1. **Collects** per-library metaDMG and unicorn output files into cached combined tables.
2. **Computes CCC damage-fit statistics** (expected vs fitted damage) for Eukaryote taxa and joins those stats back to metaDMG.
3. **Builds/uses a local NCBI taxonomy SQLite DB** and derives lineage (kingdom → species).
4. **Attaches taxonomy to BOTH unicorn and metaDMG tables**.
5. Produces **final merged outputs** at:

   * **species level** (joined on `library_id + taxid`)
   * **genus level** (joined on `library_id + genus + family + kingdom` for safer joining than genus name alone)

---

## Inputs

### 1) Config file (bash-style)

You run the script with:

```bash
Rscript postprocess_unicorn_metaDMG.R CONFIG_FILE
```

Config file format:

```bash
LOG_FILE="postprocess.log"
TAX_PATH_NCBI="/path/to/ncbi"
EUK_DIR="/path/to/results_dir"
LIBRARY_LIST="/path/to/library_list.tsv"
```

Required keys:

* `LOG_FILE`: log file written during execution
* `TAX_PATH_NCBI`: folder containing `taxdump/` with `names.dmp` and `nodes.dmp`
* `EUK_DIR`: root directory containing output files (recursively searched)
* `LIBRARY_LIST`: TSV; first column = library IDs

### 2) Library list (TSV)

Example `library_list.tsv`:

```tsv
library_id
LIB001
LIB002
LIB003
```

The script uses the first column as the library list.

### 3) Expected file patterns under `EUK_DIR`

**metaDMG** inputs (recursively searched):

* `*.sort.comp.filtered.agg_ss.stat.gz`

**unicorn** inputs (recursively searched):

* `*.comp.filtered.unicorn.refstats`
* `*.acc2tax`

## Outputs

All cached intermediates and final outputs are written to:

```text
processed_data_ss/
```

### Cached intermediates

* `lca_all.tsv`

* `metaDMG_genus_level.tsv`

## File ingestion and caching

### Helper: `read_with_id(file)`

Reads one file and adds `library_id` inferred from filename:

```r
read_with_id <- function(file) {
  lib_id <- tools::file_path_sans_ext(basename(file)) %>% sub("\\..*$", "", .)
  fread(file, colClasses = "character") |>
    as.data.frame() |>
    mutate(library_id = lib_id)
}
```

### Helper: `read_or_process(output_file, path, pattern)`

Cache-first approach:

* If cached `output_file` exists → read and return
* Else → find all files matching `pattern` under `path`, read + bind, write cache

Example:

```r
lca_all_df <- read_or_process(
  file.path(OUTPUT_DIR, "lca_all.tsv"),
  EUK_DIR,
  ".sort\\.comp\\.filtered\\.agg_ss\\.stat\\.gz$"
)
```

## metaDMG processing

### Build rank-level metaDMG tables

Species:

```r
metaDMG_species <- lca_all_df |>
```

Genus (important: keep genus `taxid`):

```r
metaDMG_genus <- lca_all_df |>

```

These are cached to:

* `metaDMG_species_level.tsv`
* `metaDMG_genus_level.tsv`

## CCC damage-fit statistics (metaDMG)

### Goal

Compute concordance (CCC) between:

* expected forward damage: `fwf1`, `fwf2`, ...
* estimated forward damage: `fwdx1`, `fwdx2`, ...

…and add CCC summary columns back onto the metaDMG dataframe.

### Function: `dmg_fwd_CCC(df, smp, ci, nperm, nproc)`

Key behavior:

* Parallelizes over libraries using `furrr` and `future::multisession`
* For each library:

  * pivots `fwf*` and `fwdx*` wide→long
  * extracts numeric index `x`
  * joins expected vs fitted by `(tax_name, library_id, x)`
  * computes CCC per `tax_name`
  * optionally runs a permutation test (perk) if `nperm` is set

Example call:

```r
ccc_stats <- dmg_fwd_CCC(
  df    = holi_data_sp_euk,
  smp   = lib_ids,
  ci    = "asymptotic",
  nperm = 100,
  nproc = 14
)
```

CCC output columns (typical):

* `rho_c`, `rho_lwr_ci`, `rho_upr_ci`
* `C_b`, `l_shift`, `s_shift`
* `rho_c_perm`, `rho_c_perm_pval` (if permutation enabled)
* `library_id`

### Function: `add_metadmg_ccc_stats(df, samples, ...)`

* filters metaDMG rows to Eukaryotes (`taxa_path` contains “Eukaryota”)
* renames `taxid` → `tax_name` for CCC computation
* computes CCC
* left-joins CCC results back to the full metaDMG df by `(library_id, taxid)`

Example integration:

```r
lca_all_df <- add_metadmg_ccc_stats(
  df      = lca_all_df,
  samples = lib_ids,
  ci      = "asymptotic",
  nperm   = 100,
  nproc   = 14
)
```

**Effect:** `lca_all_df` now contains CCC columns for taxa where CCC was computable (others get NA).

## unicorn processing

### Combine and join unicorn inputs

Load/cache combined tables:

```r
stats_all_df <- read_or_process(
  file.path(OUTPUT_DIR, "stats_all.tsv"),
  EUK_DIR,
  ".comp\\.filtered\\.unicorn\\.refstats$"

acc2tax_all_df <- read_or_process(
  file.path(OUTPUT_DIR, "acc2tax_all.tsv"),
  EUK_DIR,
  ".acc2tax$"
)
```

Standardize column names and join:

```r
stats_all_df   <- stats_all_df   |> rename(accession = Id, n_reads_from_unicorn = n_reads)
acc2tax_all_df <- acc2tax_all_df |> rename(accession = BAM_Reference, taxid = TaxID)

stats_joined <- stats_all_df |>
  inner_join(acc2tax_all_df, by = c("accession", "library_id"))
```

## Summarization functions (unicorn tables)

### `summarise_stats_joined_all(stats_joined, ...)`

Produces species-level and genus-level unicorn summaries.

Key features:

* groups by `group_cols` (default: `library_id`, `taxid`)
* calculates:

  * `n_references` (# distinct accessions)
  * `total_reads_from_unicorn` (sum of read counts)
  * means across numeric columns
  * sums selected numeric columns (e.g. `reference_length`)
* optionally carries non-numeric columns (taxonomy strings, etc.)

Species-level:

```r
stats_species <- summarise_stats_joined_all(stats_joined)
```

Genus-level (after taxonomy join):

```r
stats_genus <- summarise_stats_joined_all(
  stats_joined = stats_species_tax,
  group_cols   = c("library_id", "genus", "family", "kingdom"),
  weight_col   = "total_reads_from_unicorn",
  exclude_cols = c("library_id", "taxid", "total_reads_from_unicorn", "n_references", "genus"),
  sum_cols     = c("reference_length")
)
```

## Taxonomy handling (for BOTH metaDMG and unicorn)

### Local taxonomy database

The script builds a SQLite DB once:

```r
sqlite_file <- "nameNode.sqlite"
read.names.sql(names_file, sqlFile = sqlite_file, overwrite = TRUE)
read.nodes.sql(nodes_file, sqlFile = sqlite_file, overwrite = TRUE)
```

### Taxonomy table: `tax_data_all_taxids.tsv`

The script creates/loads lineage data for all taxids appearing in:

* `stats_species`
* `metaDMG_species`
* `metaDMG_genus`

Example lineage fetch:

```r
tax_data <- getTaxonomy(
  tax_ids_lst,
  sqlite_file,
  desiredTaxa = c("kingdom", "phylum", "class", "order", "family", "genus", "species")
) |> as_tibble() |> mutate(taxid = tax_ids_lst)
```

### Attach taxonomy to unicorn species stats

```r
stats_species_tax <- stats_species |>
  mutate(taxid = as.integer(taxid)) |>
  inner_join(tax_data |> mutate(taxid = as.integer(taxid)), by = "taxid")
```

### Attach taxonomy to metaDMG species + genus (always)

```r
metaDMG_species <- metaDMG_species |>
  mutate(taxid = parse_integer(as.character(taxid))) |>
  left_join(tax_data, by = "taxid")

metaDMG_genus <- metaDMG_genus |>
  mutate(taxid = parse_integer(as.character(taxid))) |>
  left_join(tax_data, by = "taxid") |>
  mutate(
    genus   = as.character(genus),
    family  = as.character(family),
    kingdom = as.character(kingdom)
  )
```

**Why this matters:** genus-level merging now uses taxonomy-derived `genus/family/kingdom`, not just a free-text genus name.

## Final merges

### Species-level merge (safe keys)

Joins unicorn and metaDMG species by stable identifiers:

```r
bf_md_species <- stats_species_tax |>
  mutate(library_id = as.character(library_id),
         taxid      = as.integer(taxid)) |>
  inner_join(
    metaDMG_species |> mutate(taxid = as.integer(taxid)),
    by = c("library_id", "taxid")
  )
```

### Genus-level merge (safer than genus-only)

Joins by:

* `library_id`
* `genus`
* `family`
* `kingdom`

```r
bf_md_genus <- stats_genus |>
  mutate(
    library_id = as.character(library_id),
    genus      = as.character(genus),
    family     = as.character(family),
    kingdom    = as.character(kingdom)
  ) |>
  inner_join(
    metaDMG_genus |>
      mutate(
        library_id = as.character(library_id),
        genus      = as.character(genus),
        family     = as.character(family),
        kingdom    = as.character(kingdom)
      ),
    by = c("library_id", "genus", "family", "kingdom")
  )
```

## Final writeout

Writes final merged TSVs if missing or empty:

```r
fwrite(bf_md_species, merged_species_file, sep = "\t", quote = FALSE)
fwrite(bf_md_genus,   merged_genus_file,   sep = "\t", quote = FALSE)
```

## Quick “what do I get in the outputs?”

### `merged_stats_metaDMG_species_level.tsv`

Per `(library_id, taxid)` row, includes:

* unicorn species summary metrics (`total_reads_from_unicorn`, etc.)
* metaDMG species metrics (`total_n_reads_from_mD`, damage columns, etc.)
* CCC statistics columns (where computable)
* taxonomy columns (kingdom→species)

### `merged_stats_metaDMG_genus_level.tsv`

Per `(library_id, genus, family, kingdom)` row, includes:

* unicorn genus-level summary metrics
* metaDMG genus metrics
* taxonomy columns enabling safe grouping + joining

```r
bf_md_genus_summary <- summarise_bf_genus(

)
```
